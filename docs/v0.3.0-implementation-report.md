# v0.3.0 — What Changed

## Added

- **PR diff reading:** 3 tools (`github_get_pr_files`, `github_get_pr_commits`, `github_get_file_contents`) let agents review PRs without a local git checkout
- **Review lifecycle:** 10 tools — resolve/unresolve threads, merge PR, request reviewers, manage labels and assignees, dismiss stale reviews, delete comments, and new search filters
- **Jira tools:** 5 previously hidden client methods exposed — `jira_get_comments`, `jira_list_transitions`, `jira_list_issue_link_types`, `jira_search_users`, `jira_delete_comment`
- **Confluence:** `confluence_whoami` exposed (was unreachable)
- **Figma:** `depth`/`ids` params for narrowing file responses, and `figma_post_comment` for design feedback
- **Shared helpers:** retry logic, repo validation, PR detail mapping, and issue key patterns consolidated from duplicated code

## Fixed

- **Schema advertisement:** multi-step validations now show all tool parameters (fixes `github_create_pr_review_comment` which was previously uncallable)
- **Branch search:** no longer returns empty results when `searchBranches` is true
- **Pagination:** no more phantom empty pages on exactly-full last pages; cursors work correctly
- **Jira response shape:** always returns the compact format regardless of requested fields
- **Error messages:** API errors now carry descriptive messages instead of generic status codes
- **Resource routing:** URI lookups dispatch to the correct handler instead of returning the last failure
- **Branch cache:** now expires after 60 seconds instead of living forever
- **Figma client:** added timeout protection (was missing)
- **Configuration:** token no longer leaks into loggable config object

## Changed

- **Tool count:** 43 → 64
- **Test count:** 362 → 582 (5 new test files)
- **Confluence responses:** now use the standard paginated envelope
- **PR details:** now include requested reviewers, teams, labels, and assignees
- **Retry behavior:** handles secondary rate limits and network resets that were previously missed
